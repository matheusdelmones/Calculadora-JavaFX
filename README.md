# Calculadora JavaFX - Teoria e Prática de POO

Este projeto é uma calculadora desktop funcional desenvolvida em Java. O objetivo principal foi aplicar conceitos de **Programação Orientada a Objetos** em uma interface gráfica real.

## 🚀 Funcionalidades
- Operações de soma, subtração, multiplicação e divisão.
- Interface responsiva com `GridPane`.
- Estilização via **CSS externo** para separação de responsabilidades.
- Tratamento de exceção para divisão por zero.

## 🛠️ Tecnologias
- **Java 17**
- **JavaFX 17**
- **CSS**

## 🧠 Conceitos Aplicados
- **Herança**: Extensão da classe `Application`.
- **Polimorfismo**: Gerenciamento de eventos de botões.
- **Encapsulamento**: Lógica de cálculo isolada da interface.
